## Scope and risks

No engine, prompt, settings or UI change. No local application installation.
The fix preserves finite-buffer audio tails and restores configured WAV
retention; it does not establish the cause of every historical missing phrase.
The existing release workflow publishes macOS only. Publication depends on
GitHub-hosted signing credentials and Apple's notarization service.

## Failing-first evidence and minimal CI repair

Desktop CI run [40012962883](https://github.com/okafrancois/voiceflow/actions/runs/40012962883)
failed on the unchanged v1.4.0 commit: async-trait 0.1.89 emits redundant
`must_use` attributes rejected by Clippy 1.99, and the media converter uses
a mutable binding on Windows although it only mutates it on macOS.
The upstream [async-trait 0.1.92 release](https://github.com/dtolnay/async-trait/releases/tag/0.1.92)
fixes that generated-code lint. Upgrade only that dependency and make the
temporary-file binding mutable only on macOS. Existing tests and CI provide
the checks for these compatibility repairs.
