# Voice Flow Trademark Policy

## Overview

This document outlines the terms for using Voice Flow trademarks and brand assets. While Voice Flow's source code is open source under GNU Affero General Public License v3.0 (AGPL-3.0), Voice Flow's trademarks, logos, and brand identity are separately protected.

## What are Trademarks

Voice Flow trademarks include but are not limited to:
- "Voice Flow" name
- Voice Flow logo and icons
- Voice Flow product names and taglines
- Voice Flow visual design elements and brand identity

## Permitted Uses

### Uses Without Permission

You may use Voice Flow trademarks without explicit permission in these cases:

1. **Accurate Description**: Using trademarks when describing or referencing Voice Flow software
   - Example: "This application is built on Voice Flow"
   - Example: "Compatible with Voice Flow"

2. **Educational and News**: Using in articles, tutorials, reviews, or news coverage
   - Must accurately and objectively describe Voice Flow
   - Must not imply official endorsement or affiliation

3. **Community Discussion**: Mentioning Voice Flow in forums, social media, or technical discussions
   - Must clearly state you don't represent Voice Flow officially

### Uses Requiring Permission

You must obtain written permission for:

1. **Commercial Product Naming**: Using Voice Flow trademark in product or service names
2. **Domain Registration**: Registering domains containing Voice Flow
3. **App Store Publishing**: Publishing apps using Voice Flow name or logo
4. **Merchandise Sales**: Using Voice Flow trademark on T-shirts, stickers, etc.

## Prohibited Uses

The following uses are explicitly prohibited:

1. **Confusing Use**: Using trademarks in ways that may confuse users
   - Don't imply your project is an official Voice Flow project
   - Don't imply your project has official Voice Flow endorsement

2. **Disparaging Use**: Using trademarks in disparaging, defamatory, or negative ways

3. **Modifying Trademarks**: Modifying, distorting, or creating derivative versions of Voice Flow trademarks

4. **Primary Identifier**: Using Voice Flow trademark as your product's primary identifier
   - Fork projects must use different names and logos
   - Example: If you fork Voice Flow, name it "YourName Voice Transcriber" not "Voice Flow Fork"

## Fork and Derivative Work Guidelines

If you create a fork or derivative work based on Voice Flow source code:

### Must Do

1. **Use Different Name**: Choose a unique name for your project
2. **Create Own Brand**: Design your own logo and visual identity
3. **Clarify Relationship**: You may state "Based on Voice Flow" or "Fork of Voice Flow"
4. **Retain Copyright Notices**: Keep original copyright and license notices in source code
5. **Follow AGPL-3.0**: Ensure your derivative work also complies with AGPL-3.0

### Must Not Do

1. **Don't Use Voice Flow Name**: Don't name your project "Voice Flow [Something]"
2. **Don't Use Voice Flow Logo**: Don't use Voice Flow's logo or icons in your project
3. **Don't Imply Official Affiliation**: Don't imply your project is official or officially supported

### Recommended Attribution

In your README or About page, you can state:

```markdown
This project is based on [Voice Flow](https://github.com/okafrancois/voiceflow),
an open-source voice-to-text application. This project is an independent fork
and is not affiliated with the official Voice Flow team.
```

## Trademark Usage Examples

### ✅ Correct Usage

- "Our app uses Voice Flow engine for speech recognition"
- "Tutorial: How to Install Voice Flow"
- "Comparison of Voice Flow Alternatives"
- "Custom voice-to-text solution based on Voice Flow"

### ❌ Incorrect Usage

- "Voice Flow Pro" (implies official product)
- "Voice Flow for Business" (implies official version)
- "Buy Voice Flow License" (misleading commercial use)
- Using Voice Flow logo as your product icon

## Why Protect Trademarks

We protect Voice Flow trademarks to:

1. **Protect Users**: Ensure users can identify genuine Voice Flow software
2. **Maintain Quality**: Prevent low-quality or malicious software from impersonating Voice Flow
3. **Build Trust**: Maintain Voice Flow brand integrity and reputation
4. **Support Open Source**: Support project sustainability through brand differentiation
